To preserve the causal ordering $M_0 \rightarrow (L_1, A_1, Y_1) \rightarrow \dots \rightarrow (L_{12}, A_{12}, Y_{12})$—where $L_m$ (TDC) precedes $A_m$ (PSP_SPE_COD), which in turn precedes $Y_m$—each monthly block $M_m$ ($m \in \{1, \dots, 12\}$) corresponds to the 30-day window $[30(m-1), 30m)$ ending at day $t_m = 30m$.1. Step-by-Step AlgorithmSort & Extract Subject-Level Baseline ($M_0$) and Terminal Outcome:Sort the longitudinal dataset by BEN_IDT_ANO, start, and stop.For each participant (BEN_IDT_ANO):Extract $M_0$: the constant baseline covariates from the participant's first row.Extract final follow-up time $T_{\text{end}} = \max(\text{stop})$ and final outcome $E_{\text{end}}$ (event_num on the last row, or $\max(\text{event\_num})$).Compute the terminal month index:If $E_{\text{end}} > 0$ (event or competing event occurred):$$k_{\text{event}} = \max\left(1, \left\lceil \frac{T_{\text{end}}}{30} \right\rceil\right)$$If $E_{\text{end}} = 0$ (right-censored):$$k_{\text{cens}} = \left\lfloor \frac{T_{\text{end}}}{30} \right\rfloor$$Map Longitudinal Rows onto Monthly Grids ($m = 1, \dots, 12$):Each row $r$ represents an exposure/covariate update initiated at start (with TDC measured just prior to start and PSP_SPE_COD assigned at start).Assign each row to the month $m_{\text{start}} = \lfloor \text{start} / 30 \rfloor + 1$ (so start = 0 maps to $M_1$, start = 30 maps to $M_2$, etc.).Handling multiple rows within the same month $m$: Keep (TDC, PSP_SPE_COD) paired from the same row so temporal precedence ($L_m \prec A_m$) is never broken—typically taking the last dispensing row starting before $30m$ (or the first row inside $[30(m-1), 30m)$ if you want the earliest treatment decision of that month).Handling months with no new dispensing (LOCF): If a participant is still under observation in month $m$ ($m \le k_{\text{event}}$ or $m \le k_{\text{cens}}$) but had no new dispensing inside $[30(m-1), 30m)$, carry forward (TDC, PSP_SPE_COD) from the most recent prior row (start < 30m).Assign Cumulative Outcome $Y_m$ and Enforce Absorbing / Censoring Rules:If $E_{\text{end}} > 0$ (event occurred in month $k_{\text{event}}$):For $m < k_{\text{event}}$: $L_m, A_m$ populated; $Y_m = 0$.For $m = k_{\text{event}}$: $L_m, A_m$ populated (from the interval active prior to $T_{\text{end}}$); $Y_m = E_{\text{end}}$ (1, 2, etc.).For $m > k_{\text{event}}$: $Y_m = E_{\text{end}}$ (absorbing state carried forward), and $L_m = \text{NA}$, $A_m = \text{NA}$ (participant is no longer at risk after the terminal event).If $E_{\text{end}} = 0$ (censored):For $m \le k_{\text{cens}}$: $L_m, A_m$ populated; $Y_m = 0$.For $m > k_{\text{cens}}$: $L_m = \text{NA}$, $A_m = \text{NA}$, $Y_m = \text{NA}$.Pivot to Wide Format in Strict Block Order:Arrange columns as: BEN_IDT_ANO, [baseline_vars], followed sequentially by [TDC_1, A_1, Y_1], [TDC_2, A_2, Y_2], ..., [TDC_12, A_12, Y_12].
